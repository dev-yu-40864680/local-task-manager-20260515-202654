# Local Task Manager

ブラウザのローカルストレージで完結する、個人用のWebタスク管理アプリです。
データは外部に送信されず、すべて `localStorage` に保存されます。

## 主な機能

- タスクの追加 / 編集 / 削除 / 完了切り替え
- 優先度（高 / 中 / 低）
- 期限（日付）設定
- タグ（複数）
- カンバン表示（TODO / 進行中 / 完了）+ ドラッグ&ドロップで状態遷移
- テキスト検索・優先度・タグ・期限によるフィルタ
- ダークテーマ（控えめなトーン）
- ログイン不要
- 100件上限：超過時は新規追加を拒否しエラー表示
- 保存データ破損検知：警告を表示し、破棄して初期状態に復帰

## 技術スタック

- Vite + React + TypeScript
- 永続化: `localStorage` のみ（外部送信なし）

## 動作要件

- Node.js 18 以上
- npm 9 以上

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## ビルド

```bash
npm run build
npm run preview
```

## データの保存場所

ブラウザの `localStorage` キー `local-task-manager:tasks:v1` に保存されます。
別ブラウザ・別端末への自動同期は行いません。
